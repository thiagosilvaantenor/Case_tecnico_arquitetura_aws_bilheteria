# Case_tecnico_arquitetura_aws_bilheteria
## Proposta​
Propor uma arquitetura na AWS para um sistema de bilhetagem com as seguintes características:  
​Permitir a solicitação, a reserva e a compra de ingressos;  
​Oferecer produtos adicionais durante o processo de compra, como pipoca, chocolate e refrigerante.  
​📋 O que esperamos  
​Um desenho da arquitetura AWS, que pode ser elaborado com ferramentas como Lucidchart, Draw.io ou similares;  
​Uma breve documentação explicando suas decisões técnicas.  
​📌 Adicional  
​Traga um código, na sua linguagem de domínio, que você tenha desenvolvido e/ou tenha participado do desenvolvimento. O código não precisa estar relacionado ao contexto do desenho da solução acima.
